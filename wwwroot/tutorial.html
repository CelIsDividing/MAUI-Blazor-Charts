Uvod

Ovo je kompletna aplikacija koja demonstrira kako kombinovati MAUI, Blazor WebAssembly i Chart.js biblioteku za prikaz dinamičkih grafika sa MVVM arhitekturom.

✅ Status: Aplikacija je potpuno funkcionalna i sprema za korišćenje!

Originalni zahtevi

  • Napraviti MAUI + Blazor aplikaciju
  • Kreirat ViewModel koji izlaže niz brojčanih ili tekstualnih vrednosti
  • Dodati ListView sa više "kartice"
  • Kartice povezane sa vrednostima iz niza
  • Nekoliko tipova grafikona: bar, pie, round gauge, historical plot
  • Funkcionalnost za izmenu vrednosti sa dinamičkim promema
  • WeakReferenceMessenger iz MVVM Toolkit paketa
  • Besplatna chartinga biblioteka (LiveCharts / Chart.js)
  • Mali tutorijal za upotrebu biblioteke

Arhitektura aplikacije

Aplikacija koristi modernu MVVM (Model-View-ViewModel) arhekturu sa sledećim slojevima:

Modeli podataka (Models/)

Definiše domenske objekte:

  • ChartItem - Predstavlja jednu karticu sa grafikom
  • DataPoint - Jednu tačku sa vremenskom oznakom
  • ChartType - Enum sa tipovima grafikona

ViewModels (ViewModels/)

MainViewModel.cs - Centralni koordinator:

  • Upravlja kolekcijom grafikona
  • Implementira RelayCommand-e za korisničke akcije
  • Koristi WeakReferenceMessenger za komunikaciju
  • Observable kolekcije za reaktivnost

Servisi (Services/)

  • DataService - Generiše test podatke
  • MessengerMessages - Definiše poruke za inter-komponentnu komunikaciju

Prikazi (Pages/)

  • App.razor - Root komponenta sa rutama
  • Index.razor - Početna stranica
  • Charts.razor - Stranica sa graficima
  • Tutorial.razor - Tutorijal

MVVM Toolkit

Koristi se CommunityToolkit.Mvvm v8.2.2 za implementaciju MVVM patterna.

Ključne komponente:

1. ObservableProperty - Automatska notifikacija

Atribut koji generiše property sa notifikacijom:

[ObservableProperty]
ObservableCollection<ChartItem> charts;

Automatski generiše Charts property sa `PropertyChanged` notifikacijom.

2. RelayCommand - Korisničke akcije

Definiše komande za dugmiće i akcije:

[RelayCommand]
void IncreaseValue(string chartId) { /* logika */ }

Kreira IncreaseValueCommand koji se može bindovati na UI dugmiće.

3. WeakReferenceMessenger - Inter-komponentna komunikacija

Omogućava slanje poruka između komponenti bez direktne reference:

WeakReferenceMessenger.Default.Send(
  new ChartValueChangedMessage { ChartId = id, NewValue = value }
);

4. Observable kolekcije

Reaktivne kolekcije koja signaliziraju promene:

ObservableCollection<ChartItem> charts = new();

Chart.js biblioteka

Koristi se Chart.js 4.x iz CDN-a za renderovanje grafikona.

Inicijalizacija grafikona:

const barCtx = document.getElementById('barChart').getContext('2d');
const barChart = new Chart(barCtx, {
  type: 'bar',
  data: {
    labels: ['Jan', 'Feb', 'Mar'],
    datasets: [{ label: 'Prodaja', data: [15000, 25000, 20000] }]
  },
  options: { responsive: true, maintainAspectRatio: false }
});

Ažuriranje grafikona:

barChart.data.datasets[0].data = [16000, 26000, 21000];
barChart.update();

Blazor Komponente

Aplikacija sadrži 4 glavne kartice za različite tipove grafikona:

Komponenta Tip Grafikona Lokacija Opis
BarChartCard Bar Pages/ Stubičasti grafikon sa +/- kontrolama
PieChartCard Pie Pages/ Kruzni dijagram za procente
RoundGaugeCard Gauge Pages/ Okrugla mera sa iglom
HistoricalPlotCard Line Pages/ Linijski grafikon kroz vreme

Struktura komponente:

  • @component direktiva sa html-om
  • [Parameter] svojstva za podatke
  • EventCallback za komunikaciju sa parent komponentom
  • OnInitialized/OnInitializedAsync za inicijalizaciju

Pokretanje aplikacije

Preduslovi:

  • .NET 10.0.101 SDK instaliran
  • Visual Studio Code ili VS 2022
  • Terminal (PowerShell, CMD ili bash)

Koraci:

# 1. Ulazi u folder
cd "c:\Users\krist\Documents\Fakultet\New folder\MauiBlazorCharts"

# 2. Čisti stari build
dotnet clean

# 3. Gradi projekat
dotnet build

# 4. Pokreće aplikaciju
dotnet run --urls "http://localhost:5002"

# 5. Otvori u browser-u
http://localhost:5002/charts.html
Rezultat: Trebalo bi da vidite "Now listening on: http://localhost:5002" i 4 dinamička grafikona!
